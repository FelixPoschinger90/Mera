MERA · ZERO-COST VOICE SCREENING

Kokoro neural voice test

This is deliberately separate from the game. It tests three fixed female voices before we rebuild MERA again. On first load, the browser downloads an open-source Kokoro speech model (roughly 86–100 MB in the quantized version) and caches it locally.

Press “Load voice engine” first.

No account, API key, subscription, or paid service is used. Speech is generated in your browser after the model files load.
